# Public-Domain Modern Cursive Hebrew Benchmark (`benchmark/modern_cursive`)

This corpus provides **verified, public-domain (`PDM-1.0`) modern cursive Hebrew manuscript pages** with independently reviewed transcripts so OCR and post-OCR modules can be measured reproducibly without fabricating ground truth or violating student privacy.

## Scope and Relationship to Other Corpora

1. **`benchmark/modern_school/`** remains reserved exclusively for contemporary classroom student pages collected under written school consent (`benchmark/modern_school/README.md`). Nothing in this folder claims to be contemporary K–12 classroom student work.
2. **`benchmark/modern_cursive/` (this folder)** holds 6 complete, human-reviewed public-domain (`PDM-1.0`) modern cursive Hebrew manuscript pages (1892–1930) indexed by [`HeOCR/hash`](https://github.com/HeOCR/hash) (`CC0-1.0`) with public-domain editions from Hebrew Wikisource:
   - Multiple writers (Rachel Bluwstein across 4 distinct pens/papers, Hayyim Nahman Bialik, Naftali Herz Imber).
   - Real physical paper challenges: **graph-ruled notebook paper (`נייר משובץ`)**, **wide-spaced 4-line notes**, **low-resolution faint cursive strokes (`370×550`)**, **archival stamps/shelfmarks**, and **authorial strike-throughs / interlinear draft revisions** (`commons__rachel_aqara_1928__p0001`).
   - None of these 6 pages appear in `Mishkefet-v1`'s published `Pinkas` or `BiblIA` training sets.
3. **Pinkas (`--pinkas`, ICDAR 2019, `CC-BY-4.0`)** remains a separate historical/early-modern (1500–1800) cursive diagnostic corpus.
4. **`benchmark/smoke_test/pages/scan-2026-10-28-221624.pdf`** remains an **unverified** contemporary 28-line lined notebook cursive scan used strictly for segmentation completeness, latency, and memory diagnostics (never for CER/WER claims).

## Transcript Integrity Rules

- All 6 transcripts in `transcripts/` are **verbatim** upstream files from `HeOCR/hash` (`status: "reviewed"`, `created_by: "repo"`). Entries in `HeOCR/hash` generated by LLMs (`created_by: "ocr"`) were excluded.
- No ground-truth transcript was generated or edited to fit any OCR model's output.
- Run `python tools/build_benchmark.py --corpus benchmark/modern_cursive --strict` to verify SHA-256 image digests and transcript completeness.

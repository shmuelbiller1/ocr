# Sample files

Everything in this folder was generated by `tools/make_samples.py`. The
pages are **synthetic**: they contain no real handwriting, no real
document and no personal data. They exist so that the preview, the zoom,
the rotation, the page navigation and the editor can be tried without
using anyone's actual scans.

| File | What it is | What it is good for |
| --- | --- | --- |
| `scan_page_1.png`, `scan_page_2.png` | A4 pages at 150 dpi with ink-like strokes | Testing the image preview, zoom, rotation and the page navigation |
| `two_pages.pdf` | A two page PDF | Testing PDF rasterisation and page navigation |
| `sample_text_hebrew.txt` | A short Hebrew text | Typing or pasting text into the editor, testing the right-to-left layout, the `.txt` export and the printing |

Regenerate them with:

```bash
python tools/make_samples.py
```

The handwriting accuracy benchmark does **not** use these files. It uses
real handwritten pages with a known transcription; see
`docs/OCR_ACCURACY.md` for the corpus, its licence and the measured
numbers.
